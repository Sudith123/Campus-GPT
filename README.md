## Run locally

This repository contains the Campus-GPT application.

View your app in AI Studio: https://ai.studio/apps/45d30deb-8402-4ace-973d-180cb97010d4

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Create a `.env` file from `.env.example` and set the required values.
3. Run the app:
   `npm run dev`
